# 轻量档案规范（light-archive.md）

**目标**：全过程可溯源，但零负担——无 git 仓库时自动存主 Agent 工作区；有仓库时可升级企业级（archive-format.md）。

## 存储位置

- **无仓库（默认）**：主 Agent 工作区 `<workspace>/collab-archive/`（每任务一个 md 文件）
- **有仓库**：`<项目根>/collab-archive/`（或按 archive-format.md 升级企业级：索引/RV/raw）

## 每任务档案最小字段

```markdown
# <任务名>（<YYYY-MM-DD>）

## 基本信息
- 类型：简历制作 / 日常工作 / 搜索调研 / 写作 / 方案 / 其他
- 目标：…
- 交付物：<文件名或链接>

## 方案要点（事前对齐结论）
- 关键取舍：…
- DeepSeek 意见：通过 / 有条件通过（条件：…）/ 拒绝（原因：…）

## 关键证据（联网取证）
| 事实 | 来源 URL | 等级 | 状态 |
|---|---|---|---|
| … | … | S/A/B/C | 已查证 / 一方称 / 未查到 |

## 复核记录（事后）
- DeepSeek 结论：通过 / 有条件通过 / 拒绝 + 要点
- 修复动作：…

## 待拍板事项（如有）
- [ ] …（附收益评估选项）
```

## 纪律

- **当日记录**：任务完成当天落档，不事后补记
- **结论三态如实**：拒绝就是拒绝，不粉饰
- **证据链**：关键结论必须能回溯到档案里的来源 URL（溯源：交付物 → 档案 → 来源）
- **拍板项不积压**：待拍板事项列出选项 + 收益评估，等用户裁决

## 升级路径

需要更强可溯源（代码项目/多轮评审/审计）时：按 [archive-format.md](archive-format.md) 升级企业级（索引.md + raw/ + RV 编号 + frontmatter + diff_hash），并把 collab-archive 迁移为 reviews/。
